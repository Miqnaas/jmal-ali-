# Tahreek Sound Design

A responsive Egyptian Arabic / English sales landing page, upgraded from the supplied V4 prototype.

```sh
npm ci --cache /tmp/tahreek-npm
npm run dev -- --port 5173
```

Run `npm run lint`, `npm test` (with dev server running) and `npm run build`.

See [HANDOFF.md](HANDOFF.md) for configuration, screenshots, validation and launch dependencies. Checkout, campaign dates, callback endpoint and approved media are intentionally unconfigured.
